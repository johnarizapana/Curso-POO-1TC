# Proyecto POO Python

Estructura básica de un proyecto de Programación Orientada a Objetos en Python con un ejemplo de la clase Persona.

Estructura:
- src/persona/persona.py  -> Clase Persona
- examples/main.py        -> Ejemplo de uso
- tests/test_persona.py   -> Tests simples con pytest

Instrucciones:
1. Crear y activar un entorno virtual: python -m venv .venv && .\.venv\Scripts\Activate
2. Ejecutar ejemplo: python examples\main.py
3. Ejecutar tests: pytest
